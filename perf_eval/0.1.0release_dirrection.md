Optional: machine-calibrated profile

Do not benchmark automatically during pip install. Installation should remain deterministic and fast.

Instead, provide an explicit command or Python API:

fortran-nlp-calibrate


Conceptually:

detect CPU and logical/physical cores
→ run short representative benchmarks
→ find local crossover thresholds
→ identify suitable OpenMP/OpenBLAS thread counts
→ save profile locally


For example:

~/.config/fortran-nlp-kernels/cpu_profile.json


Then resolution becomes:

explicit backend selected by user
→ use explicit choice

backend="auto" + saved calibration profile
→ use machine-calibrated policy

backend="auto" without profile
→ use packaged benchmark-informed defaults


Also allow users to ignore or delete the profile.
